# SEO Checklist for Leelabiologics

## Technical SEO (Implemented)

✅ **Meta Tags**
- Unique title tags for each page (max 60 chars)
- Meta descriptions for each page (max 160 chars)
- OpenGraph and Twitter Card tags
- Canonical URLs

✅ **Structured Data (JSON-LD)**
- Organization schema on all pages
- Sitemap generated dynamically

✅ **Site Structure**
- Clean URL structure (`/solutions/biologics-cdmo/`)
- robots.txt configured
- XML sitemap at `/sitemap.xml`

✅ **Performance & Core Web Vitals**
- Server-side rendering for SEO-critical pages
- Image optimization with Next.js Image
- Font preloading with `display=swap`
- CSS custom properties for minimal CSS

## Content SEO Checklist

### For Each New Page

- [ ] **Title Tag**: Unique, keyword-rich, under 60 characters
  - Format: `[Primary Keyword] - [Secondary Keyword] | Leelabiologics`
  
- [ ] **Meta Description**: Compelling, action-oriented, under 160 chars
  - Include primary keyword
  - Include call-to-action

- [ ] **H1 Tag**: One per page, includes primary keyword

- [ ] **Header Hierarchy**: Proper H2, H3, H4 structure

- [ ] **Content Length**: 
  - Pillar pages: 1,500-3,000 words
  - Service pages: 800-1,500 words
  - Blog posts: 800-2,000 words

- [ ] **Internal Links**: 3-5 relevant internal links per page

- [ ] **Image Optimization**:
  - Descriptive filenames (e.g., `gmp-manufacturing-facility.webp`)
  - Alt text with keywords
  - WebP format
  - Lazy loading

### Pillar Page Requirements

Each pillar page should have:
- Comprehensive coverage of the topic
- FAQ section with structured data
- Related case studies/resources
- CTA sections
- Internal links to related content

## Monthly SEO Tasks

1. **Review Analytics**
   - Check organic traffic trends
   - Identify top-performing pages
   - Find underperforming pages to optimize

2. **Content Updates**
   - Update date stamps on key pages
   - Add fresh content/statistics
   - Review and fix broken links

3. **Technical Audit**
   - Run Lighthouse audit
   - Check Core Web Vitals
   - Verify sitemap is up-to-date
   - Check for 404 errors

4. **Keyword Monitoring**
   - Track rankings for target keywords
   - Identify new keyword opportunities
   - Analyze competitor movements
